# 🎵 Atif Aslam Top 5 Songs Webpage 🌲


I created a simple webpage that shows the top 5 songs by Atif Aslam according to my personal taste. 🎸 

The cool part? You can easily listen to the tracks just by clicking on the name of the song, which will direct you straight to YouTube! 📺


This entire project was built using only two things:
* **HTML** to structure the content, and YouTube links. 🏗️
* **Internal CSS** to style the page, colors, and layout all within a single file. 🎨
